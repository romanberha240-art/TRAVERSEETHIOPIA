# Fixes delivered for Traverse Ethiopia

This repository has been updated to reflect the fixes included in the `traverse-ethiopia-fixes.zip` package.

What was restored:
- working static server entry point via `server.js`
- API endpoints for health, gallery and inquiry handling
- missing gallery page and destination pages
- itinerary pages used by site navigation
- contact/inquiry form support and JSON handling
- project runtime configuration for Node deployments

How to run:

```bash
npm install
npm start
```

Then open:

- http://localhost:3000/
- http://localhost:3000/gallery.html
- http://localhost:3000/destinations.html
